- 命令通过结构体定义（`TopLevelCommandDef` / `AliasCommandDef`）集中声明 name/handler/usage/help，并在 `init()` 中统一注册，再由运行时查找分发。
- 别名命令支持按 `aliasKind`（superrepo/repo/dataset/stage/namedgraph/ibnode）复用同一命令名，并通过 `ByKind` 映射为不同上下文提供差异化 handler。
- 交互式命令执行包裹在匿名函数内使用 `defer recover()` 捕获 panic，保证单个命令异常不会退出 REPL。
- 环境变量加载遵循“不覆盖已有值”原则，从当前工作目录到用户家目录顺序扫描 `.env.sst-cli`，缺失视为非致命。
- 每个资源域（repository/dataset/stage/namedgraph/ibnode/filterextract/document/history）拆分为独立 handler 文件，便于按领域扩展与维护。
- 版本、构建时间、提交哈希通过包级变量配合 `go build -ldflags -X` 注入，而非编译期常量。
