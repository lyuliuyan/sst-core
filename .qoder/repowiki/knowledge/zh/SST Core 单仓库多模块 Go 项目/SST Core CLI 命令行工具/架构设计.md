模块以 `main.go` 为唯一入口，调用 `utils.LoadEnvSstCLI()` 加载 `.env.sst-cli` 环境变量后进入 `cmd.Execute()`。
- `cmd/root.go` 定义根命令 `sst`（默认进入交互模式）并挂载 `interactive.InteractiveCmd` 与 `versionCmd`；帮助函数被包装以追加交互式模式提示。
- `cmd/version.go` 通过 `go build -ldflags` 注入 `version/buildTime/commit` 变量输出版本信息。
- `cmd/interactive/` 实现交互式 REPL：`interactive.go` 使用 `chzyer/readline` 构建带历史、自动补全和 panic 恢复的命令循环，解析输入后分派到顶层命令或别名命令；`command_parse.go` 负责语法解析，`completer.go` 提供补全。
- 命令注册采用集中式注册表模式：`command_registry.go` 在 `init()` 中注册所有顶层命令与别名命令（按 `aliasKind`——superrepo/repo/dataset/stage/namedgraph/ibnode 分类），并构建多张索引映射（按名称、按 kind、按命令名反向查 kind）供分发与补全使用。
- 各领域处理器文件（`repository_handler.go`、`dataset_handler.go`、`stage_handler.go`、`namedgraph_handler.go`、`ibnode_handler.go`、`filterextract_handler.go`、`document_helpers.go`、`history_graph.go` 等）按资源域拆分，仅依赖注册表与 utils。
- `cmd/utils/` 提供跨命令共享能力：环境加载、日志、分页打印、diff、BoltDB dump、令牌获取、错误封装等。
- 依赖方向单向：`main → cmd → interactive + utils`，交互层不反向依赖 utils 以外的上层包。
