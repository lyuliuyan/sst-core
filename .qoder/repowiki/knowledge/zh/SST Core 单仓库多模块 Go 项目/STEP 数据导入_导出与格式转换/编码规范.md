- 每个转换入口以 `func Xxx(graph sst.NamedGraph) (sst.NamedGraph, error)` 形式暴露，接收/返回 SST 命名图，保持无副作用的函数式风格。
- AP242 XML 的双向实现共用一组 XML 结构体（如 `Part`、`Occurrence`、`ShapeElement`、`UIDRef`），导入与导出分别定义对应版本以保持字段对称。
- P21 解析采用多阶段流水线：先 `ParseRaw` 产出原始 ssmeta 图，再经 `extractMetaDataFromP21Dataset`、`mapSingleEntitiesToDraftOntology`、`assignComplexOntologyTypes`、`mapExplicitSSTSemantics`、清理 pass 等多步方法逐步转换，临时 IR 在末尾显式删除。
- 实体映射通过 `ssmeta.StepImEntityMap` 与 `StepImMapAttributeOrder` 等元数据声明驱动，而非硬编码 switch，使新增 STEP 实体只需扩展词汇表。
- 单位与量值归一化统一通过 qau 词汇表查找：根据 `measureType` 映射表或 QAU label 匹配得到 `sst.Element`，再写入 `rep.GlobalUnit`、`rep.LengthValue` 等属性。
- XML UID 生成统一使用 `_` + `uuid.New().String()` 前缀，避免与真实 ID 冲突，并在多处复用 `handleUUID` 辅助函数。
