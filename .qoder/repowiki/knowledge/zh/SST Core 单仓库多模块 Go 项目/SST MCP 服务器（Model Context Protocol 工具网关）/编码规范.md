- 每个 MCP 工具通过内联定义参数结构体（带 `json` 与 `jsonschema` tag）+ `addTool` 泛型函数注册，处理器先校验必填字段再委托给 `Session` 方法。
- 所有工具返回结果统一经 `textResult` 序列化为缩进 JSON 文本，作为 `sdkmcp.TextContent` 放入 `CallToolResult.Content`。
- `Session` 中资源（repo/dataset/stage）采用「reserve alias → commit handle」两阶段模式分配 rN/dN/sN 自动别名，并用 `sync.Mutex` 保护多张同构映射与 order 切片。
- 对远端仓库的所有调用均通过 `authContextFor(repo)` 获取带 OIDC token 的 context，本地仓库则回退到 `context.Background()`。
- 错误处理遵循「参数为空时返回 `fmt.Errorf("xxx is required")`」的显式校验风格，由上层工具处理器直接透传。
