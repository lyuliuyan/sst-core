模块以 `index.proto` 为唯一契约源，声明 `sst.ssquery.IndexService` 服务及其单向流式 RPC `Search(stream SearchRequest) returns (SearchResult)`；由 `protoc` 生成 `index.pb.go`（消息）与 `index_grpc.pb.go`（gRPC 存根/服务端接口）。`remote.go` 作为该包的 Go 侧入口，提供 `NewSearchRequest`、`NewSearchResult`、`SearchResult.ToSearchResult` 三个函数，将 `bleve.SearchRequest`/`bleve.SearchResult` 通过 `goccy/go-json` 序列化为 `bytes` 字段在 gRPC 流中传输。依赖方向单向：本包仅依赖外部 `bleve` 与 `goccy/go-json`，不反向被依赖的业务逻辑直接感知底层序列化细节。
