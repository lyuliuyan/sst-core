模块按本体划分子包（rdf、rdfs、owl、xsd、sh、skos、ssmeta、sso、rep、lci、eed、qau），每个子包由 tools/compiler/compiler.go 从 .sst 源文件生成 vocabulary.go，定义 BaseIRI、ElementInfo、AsIs/AsKind 类型方法以及 sst.ElementInformer 实例；color、countrycodes、currencycodes 三个字典型子包则仅暴露 sst.Element 常量列表。顶层 vocabularies/dict/vocabularymap.go 通过 go:embed 内嵌所有 .sst 文件并维护一个全局 map[sst.Element]sst.ElementInformer，把各子包的 Element 与其 Informer 关联起来，供上层 SST Core API 做早期绑定与查询。依赖方向单向：具体本体包只依赖 sst 与更基础的本体包（如 owl 引用 rdf/rdfs/xsd），dict 层反向聚合所有子包，形成清晰的层级聚合关系。
