- 每个本体子包通过声明一个 pkg struct{ sst.ElementInfo } 并调用 sst.ElementPkg(pkg{}) 注册包级 PKG 变量。
- 每个本体常量以 `Vocabulary = sst.Vocabulary{BaseIRI: "..."}` 形式声明 BaseIRI，再导出大写命名的 Element 或 ElementInfo 实例。
- 复杂本体（owl/rdf/sh 等）为每个类/属性生成 IsXxx 与 KindXxx 接口，并在实现结构体上提供 AsIs_ 与 AsKind_ 方法以表达类型层次。
- 字典型子包（color/countrycodes/currencycodes）直接导出 sst.Element 常量集合，不定义 AsKind 类型体系。
- 所有生成文件头部统一包含 `Code generated by tools/compiler/compiler.go DO NOT EDIT.` 与版权声明。
- vocabularies/dict/vocabularymap.go 使用全局 keys 映射将各子包的 Element 键与其 ElementInformer 值配对，作为跨本体的统一查找表。
