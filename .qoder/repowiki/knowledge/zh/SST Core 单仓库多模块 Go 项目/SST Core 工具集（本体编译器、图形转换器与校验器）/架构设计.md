本模块按功能划分为若干独立子包，每个子包自成一个可独立编译/运行的 Go package：
- `compiler`：核心代码生成器，读取 RDF/OWL Turtle 本体并产出 `vocabularies/` 下的类型化 Go 文件；`compiler.go` 编排加载、预处理与生成流程，`reasoner.go` 实现 OWL 微型推理器以计算类包含关系并生成 `AsKind_*` 方法。
- `sst_to_svg` / `svg_to_sst`：一对对称的 2D 几何转换器，分别将 SST 内部图形表示导出为 SVG 或将 SVG 解析回 SST 结构，各自通过 `doc.go` 暴露包级入口。
- `validate`：运行时图数据校验器，封装 SHACL 与 SST 自定义规则，通过 `run.go` 统一执行入口，`shaclSstRules.go` 等文件定义具体规则。
- 编码转换小工具：`b32tob58`、`b64tob32`、`hextob58`、`bboltngr` 各自实现单一编解码任务。
所有子包均作为顶层 `tools` 包的附属工具被主工程引用，彼此之间无相互依赖，依赖方向单向指向 SST Core API。
