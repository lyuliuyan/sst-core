模块以 `doc.go` 声明包职责，围绕三个核心层次组织：
- 抽象层（`auth.go`）：定义 `AuthProvider` 接口、`SstUserInfo` 结构体以及通过 `context.Context` 存取认证提供者与用户信息的辅助函数，作为上层业务与具体实现之间的解耦边界。
- 模式与权限层（`accessmode.go`）：用有序 `int` 枚举 `AccessMode`（None < ReadOnly < ReadWrite < Admin < SuperAdmin）表达权限等级，配合 `HasAccess`、`ParseAccessMode`、`AccessModeFromRoles` 完成字符串/角色到权限等级的转换与比较。
- 实现层（`authoids.go`）：基于 `coreos/go-oidc/v3` 对 Keycloak 签发 OIDC ID Token 进行校验，使用 `go-pkgz/expirable-cache` 做 LRU 缓存并每 30s 刷新 verifier；提供 `AuthFunc`（gRPC 中间件）、`ProviderFromHeader`（HTTP 中间件）、`UnaryRBACInterceptor`、`StreamRBACInterceptor` 等拦截器，支持 super-client 与 per-repo client（通过 `#` 拼接的 audience）两种模式；通过 `Principal` 在上下文中传递已认证的邮箱、姓名、完整 claims 与 audience 列表，并由 `CheckRepoAccess` 在流式 RPC 中按方法映射 `methodRoles map[string]AccessMode` 执行细粒度 RBAC。客户端侧还提供 refresh token 与 client credentials 两种 `oauth2.TokenSource` 构造方式。
依赖方向单向：实现层依赖抽象层与模式层，不反向引用；外部仅通过公开函数与接口接入。
