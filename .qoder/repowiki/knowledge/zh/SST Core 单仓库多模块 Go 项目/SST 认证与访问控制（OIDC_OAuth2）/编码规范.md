- 通过 `context.WithValue` 与自定义私有 key 类型（如 `authenticationProvider{}`、`principalKey ctxKey`）在请求上下文中透传认证提供者与 Principal，配套提供 `FromContext` 提取函数。
- 权限等级统一使用有序 `int` 枚举（`iota` 递增），并通过 `>=` 比较实现 `HasAccess`，使权限判断直观且可排序。
- 字符串到 `AccessMode` 的解析采用大小写无关的多别名匹配（如 `read-only/read_only/readonly`、`super-admin/super_admin/superadmin`），未知值回退到安全默认值（ReadOnly 或 None）。
- gRPC 认证与鉴权以中间件形式暴露（`AuthFunc`、`UnaryRBACInterceptor`、`StreamRBACInterceptor`），由调用方组合到服务端处理器链中。
- Keycloak per-repo 标识通过固定分隔符 `#` 将 super-client ID 与仓库名拼接成 audience，并提供 `PerRepoClientID` / `IsPerRepoClientID` 配对工具函数。
- 对外部依赖（OIDC verifier、claims 解析）通过可选的测试注入参数（如 `tokenToUserInfoFuncForTest`）与 `NewOIDCVerifier` 工厂函数隔离，便于单元测试替换。
