- 测试用例统一使用 `t.TempDir()` 创建隔离工作目录，并在 `defer repo.Close()` 中释放资源。
- RDF fixture 以 `.ttl` / `.trig` / `.sst` 文件形式存放在 `testdata/` 下，通过 `testutil.LoadAllTTLFromDir` 或 `LoadTriG` 批量加载到 Stage 进行比较。
- 需要远程仓库的场景通过 `testutil.ServerServeWithOIDC` 或 `SuperServerServeWithPerRepoAuth` 启动内嵌 gRPC 服务器，并使用 `StartFakeOIDCProvider` 提供的 RS256 签名 JWT 进行鉴权。
- 断言统一使用 `github.com/stretchr/testify/assert` 的 `assert.NoError` / `assert.Equal`，错误路径使用 `require` 提前终止测试。
- 单例模式通过 `sync.Once` 包裹全局变量并提供 `GetInstance()` 访问器（见 `singleton.edmsystemdata`）。
- 测试文件命名遵循 `<feature>_test.go` 或 `<feature>/<scenario>_test.go` 结构，将同一功能的多个场景收敛到同名包的不同文件中。
