整个仓库是一个 Go module（github.com/semanticstep/sst-core），所有子包通过 Go 包导入而非进程间通信协作：sst_core 提供 RDF/SST 二进制格式与仓库抽象，cli 基于 Cobra 调用 sst_core API 暴露交互式命令，mcp_server 将同一组仓库操作包装为 MCP 工具；bboltproto 与 bleveproto 分别定义 gRPC 协议供客户端与 BBolt/Bleve 后端通信，sstauth 在 gRPC/HTTP 层注入 OIDC/OAuth2 身份并向下传递 RBAC 上下文；defaultderive 为 NamedGraph 提供 Bleve 索引派生逻辑，step_transforms 与 vocabularies 作为数据与本体常量被上层消费；tools 提供本体编译器等辅助可执行文件，examples 与 tests 分别演示用法并提供测试用例。顶层 go.mod 集中声明所有依赖，.golangci.yaml、.clang-format、copyright.tmpl 统一代码风格与版权头生成规则。
