本模块以 `repository.go` 中的 `Repository` 接口为核心契约，统一暴露数据集枚举、阶段提交、Bleve 索引管理、日志、文档存取与同步等能力；通过工厂函数 `OpenRemoteRepository`、`CreateLocalRepository`、`OpenLocalRepository`、`CreateLocalFlatRepository`、`OpenLocalFlatRepository`、`OpenLocalFlatFileSystemRepository` 按 URL/路径特征构造具体实现。

内部按存储形态分层：
- `localFullRepository`（由 `CreateLocalRepository(revisionHistory=true)` 创建）：基于 BBolt + Bleve，支持分支、commit、log、checkout、SyncFrom 等完整功能。
- `localBasicRepository`（`repolocalbasic.go`，revisionHistory=false）：同样使用 BBolt（bucket `repository`）+ Bleve，但关闭版本历史相关方法（CommitDetails/CheckoutCommit/Log 等返回 `ErrNotSupported`），通过 `view/update` 封装对 BBolt bucket 的只读/写入访问，并使用 `preCommitCondition` + `bleveIndexUpdater` 在提交后异步增量更新索引。
- `localFlatRepository`（`repolocalflat.go`）：无数据库，直接将每个 Dataset 写为 `<UUID>.sst` 或 `<base64URL(基地址)>.sst` 的独立文件，不提供 Bleve、日志、版本历史与文档功能。
- 同时存在 `localFlatFileSystemRepository` 以 `fs.FS` 抽象适配可插拔文件系统。

依赖方向：所有实现均依赖 `repoConfig`（注入 `timeNow`、`preCommitCondition`、`postCommitNotification`、`deriveInfo`、`bleveIndexUpdater`）来解耦索引更新与提交流程；权限通过 `accessModeFromDir` 在打开时探测一次并缓存为 `AccessMode_Admin` / `AccessMode_ReadOnly`；并发安全通过嵌入的 `stateControl`（`enter/leave`）保证同一时刻只有一个 Stage 操作。
