- 所有公开方法在进入时调用 `r.enter()` 并在 defer 中 `r.leave()`，通过 `stateControl` 保证 Repository 生命周期内的互斥访问。
- 不支持的功能统一返回包装后的错误：版本历史相关方法返回 `wrapError(ErrNotSupported)`，文档相关方法返回 `notSupported("...")`，避免 nil panic。
- BBolt 访问统一通过 `view`（只读）和 `update`（读写）两个封装方法，内部再根据 bucket 是否存在进行 `CreateBucketIfNotExists`，调用方不直接操作 Tx。
- Bleve 索引的注册与重建通过 `RegisterIndexHandler` 比较 `SSTDeriveInfo` 的包名/版本号决定是否重建，并将 `preCommitCondition` 与 `bleveIndexUpdater` 注入到 `repoConfig` 中以解耦提交路径。
- 仓库权限在 Open/Create 时通过 `isDirWritable` 实际写入探测一次并缓存到 `accessRight`，后续 `Info()` 直接复用而不重复 I/O。
- 扁平仓库的文件命名采用 base64URL 编码的基地址加 `.sst` 后缀，IRI 与文件名之间通过 `encodeBaseURL`/`decodeBaseURL` 对称转换。
