- 二进制字段统一使用 varint 编码长度前缀（`binary.ReadUvarint`/`PutUvarint`）表示计数与字符串长度，数值型字段使用 BigEndian 固定宽度编码。
- 字面量类型通过 `writtenLiteralKind` 枚举在写/读两侧共享，`writeLiteral` 与 `readLiteral` 均按该枚举值进行 switch 分发，新增类型需同时修改两端。
- I/O 错误处理采用显式 error 返回值配合 `panic(err)` 用于不可恢复的内部状态错误（如字典/内容读取失败），而 EOF 等边界情况通过 `errors.Is` 判断。
- 日志通过包级 `GlobalLogger` 注入，调用点统一使用 `zap.String`/`zap.Uint`/`zap.Int64` 等强类型字段记录关键中间值（如节点 fragment、计数、literal value）。
- 多段图（主图、imported、referenced）通过 `graphOffsets` 偏移表与二分查找 (`sort.SearchInts`) 定位跨图 IBNode 索引，保持三段结构对称的读写逻辑。
- 空白节点在持久化时不保存 UUID，读取时用 `uuid.NewSHA1(graphID, ...)` 基于图 ID 与节点序号重建确定性标识，确保可重复的内存状态。
