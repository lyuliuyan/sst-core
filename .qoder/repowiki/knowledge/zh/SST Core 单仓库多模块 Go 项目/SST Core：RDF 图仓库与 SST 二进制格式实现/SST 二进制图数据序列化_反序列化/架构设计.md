模块由三个文件组成，围绕 SST-1.0 二进制格式（`sstFileHeader = "SST-1.0"`）组织：
- `sstfile.go`：定义文件格式布局注释、全局日志器（`GlobalLogger`、`AtomicLevel`、`SetLogger`、`EnableDefaultLogger`）以及字面量类型枚举 `writtenLiteralKind`（String/LangString/Boolean/Integer/Double/Float/Byte/Short/Int/Long/Unsigned*/DateTime/DateTimeStamp/LiteralCollection），作为写/读两侧共享的协议常量。
- `sstwriter.go`：以 `namedGraph.SstWrite` 为入口，分三阶段写入——`sstWriteHeader`（魔法头 + graph IRI + imports + referenced graphs）、`sstWriteDictionary`（按节点排序后输出 IRI/空白节点片段与引用计数）、`sstWriteContent`（按索引写出非字面量三元组与字面量三元组）。通过 `graphWritingContext` 收集每个 IBNode 的三元组计数、导入/引用图的节点上下文，并在 `collectGraphContext` 中校验所有 import 是否可用（缺失时返回 `ErrMissingImports`）。
- `sstreader.go`：以 `SstRead` 为入口，反向执行 readHeader → readDictionary → readContent；`readLiteral` 根据 `writtenLiteralKind` 分发解码，支持新旧两种 float64 编码（`readFloat64` 大端 IEEE754 vs `readFloat64Old` varint），并提供 `SstReadOld` 兼容旧格式。读取时将空白节点用基于图 ID 与其索引的确定性 UUID（SHA1）重建，保证多次读取结果一致。
依赖方向单向：writer 与 reader 仅通过 `writtenLiteralKind` 和 `IBNode`/`NamedGraph`/`Stage` 等包级类型交互，不互相 import；字节序统一为大端整数、varint 长度前缀字符串。
