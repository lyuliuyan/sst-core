模块以单一 Go 包 `sst` 组织，按职责划分为若干子目录式文件组并通过接口解耦：
- 数据层：`core_types_and_models`（字面量类型、词汇表）与 `rdf_io`（IRI/BlankNode/Literal/Triple 模型）提供统一三元组抽象；`rdf_formats` 负责 Turtle/TriG/N-Triples 流式解析，`rdf_reader_stages` 将其转换为 Stage/NamedGraph，`rdf_writers` 反向序列化。
- 持久层：`stage_and_commit` 定义内存暂存与提交语义，`stage_fs_impl` 通过 bbolt 将 NamedGraph 映射为虚拟文件系统；`repository_core` 基于该 FS 实现 LocalBasic/LocalFull/FlatFile 三种本地仓库，`repository_remote` 提供 gRPC 客户端/服务端，`repository_super` 用 SuperRepository 聚合多个 Repository 并暴露统一配额 API。
- 传输层：`sst_file_format` 将 NamedGraph 序列化为 SST-1.0 二进制文件，`sst_diff_and_utils` 在此基础上生成/回放三元组级差分，供 Commit 增量同步使用。
- 支撑层：`hashing_and_indexing` 提供 SHA-256/Base58 哈希与 Bleve 全文索引，`support_utilities` 提供内置词典阶段与文档保险库。
跨子模块的耦合点集中在 `types.go`/`vocabulary.go` 中的公共类型与常量、`stage.go`/`dataset.go`/`namedgraph.go` 的图对象，以及 `repository.go` 中定义的 Repository/SuperRepository 接口——所有上层消费方仅依赖这些接口，具体实现可在本地、远程或 SuperRepository 之间透明替换。
