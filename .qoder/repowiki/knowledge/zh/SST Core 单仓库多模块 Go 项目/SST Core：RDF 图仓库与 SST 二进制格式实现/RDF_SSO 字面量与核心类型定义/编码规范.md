- 每个字面量类型以 Go 基础类型别名的方式实现 Literal 接口，并配套声明 _ Term = (*T)(nil) 与 _ Literal = (*T)(nil) 编译期接口一致性断言。
- 所有 XSD 字面量类型节点在 types.go 中以全局变量形式预分配（如 literalTypeInt、literalTypeBoolean），Literal.DataType() 直接返回这些不可变 IBNode 指针，避免运行时分配。
- 字面量类型通过 ibNodeString + typedResource{typeOf: &literalResourceType.ibNode} 组合构建，并设置 flags 包含 iriNodeType | stringNode，同时将 ng 指向 staticXsdGraph 或 staticRdfGraph 以区分命名空间归属。
- 新增字面量类型时需在 types.go 添加类型节点、在 literals.go 添加类型定义与方法、并在 literaltypes.go 的 literalToObject 与 literalToString 的 switch 分支中补齐映射，保持三者同步。
- RDF/RDFS/XSD/SSO/LCI 等外部词汇表均以 Vocabulary + Element 对的形式集中声明于 types.go 的包级变量中，供全包共享而非局部构造。
