本模块由三个文件组成，按职责分层：
- `types.go`：声明包级静态常量，包括三张内置命名图（staticStage、staticRdfGraph、staticSSTGraph、staticXsdGraph），所有 XSD 字面量类型节点（literalTypeString/literalTypeInt/literalTypeBoolean 等）均通过 ibNodeString 构造并挂到对应命名图上；同时集中定义 rdfVocabulary/rdfsVocabulary/xsdVocabulary/lciVocabulary/ssoVocabulary 及其常用 Element（如 rdf:type、rdfs:label、sso:Part 等）和内部 ID 命名空间。
- `literals.go`：以 Go 基础类型别名形式实现 Literal 接口的具体字面量类型（String、Byte、Short、Int、Long、Unsigned*、Double、Float、Integer、Boolean、LangString、TypedString），每个类型都实现 TermKind()、DataType() 返回对应的全局 IBNode，并通过 apiValue() 暴露原始值。
- `literaltypes.go`：提供接口 Literal 及两个关键转换函数——literalToObject 根据 literal.typeOf 将内部字节表示反序列化为各具体字面量类型，literalToString 将各类字面量格式化为字符串（含 langString 的 @langTag 后缀）。
依赖方向单向：literals.go 与 literaltypes.go 仅引用 types.go 中定义的 IBNode/Vocabulary/Element 常量，不反向依赖；整个模块作为 sst 包的基础类型层，被上层三元组操作与序列化逻辑复用。
