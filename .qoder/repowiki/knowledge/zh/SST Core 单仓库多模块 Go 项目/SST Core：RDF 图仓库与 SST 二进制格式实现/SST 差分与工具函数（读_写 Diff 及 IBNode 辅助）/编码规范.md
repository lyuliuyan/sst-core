- 差分协议采用三段式结构（Header → Dictionary → Content），读取与写入两侧分别实现对应的 `diffRead*` / `diffWrite*` 函数并保持严格对称。
- 使用 `deltaSpanT` 以 `(same|removed|added|tripleModified)` 状态序列 + `span` 压缩连续相同段，并通过 `countDeltas`/`readEntries`/`forEntries` 统一驱动双 Reader 同步扫描。
- 节点与三元组索引通过 `originToTranslated` 表在虚拟图与 delta 图之间进行双向转换，新增/删除节点时累积 `pendingVirtualToDelta` / `pendingDeltaToVirtual` 并在遇到新节点时落盘为 `virtualToDeltaTranslations` / `deltaToVirtualTranslations`。
- 对三元组排序遵循固定优先级：rdf:first 优先于其他谓词；对象类型按 IBNode < Literal < LiteralCollection；同类型内再按谓词 IRI、对象值字典序比较。
- 写入时对 rdf:first 链采用占位策略：先插入 `rdf:first` 占位三元组，待所有成员收集完毕后通过 `fillRdfFirstPlaceholder` 回填实际对象。
- 调试日志统一通过 `GlobalLogger.Debug` 并以 `zap.String`/`zap.Uint`/`zap.Array` 等字段记录关键变量（如 readerSource、fragment、translation 表），便于追踪 diff 解析过程。
