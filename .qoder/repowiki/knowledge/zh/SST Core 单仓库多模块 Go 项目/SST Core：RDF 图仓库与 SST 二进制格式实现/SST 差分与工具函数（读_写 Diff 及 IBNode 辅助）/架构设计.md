模块由三个文件构成清晰的职责分层：
- `sststreaddiff.go` 负责读取 base + diff 并重建 NamedGraph。入口 `SstReadDiff` 依次调用 `diffReadHeader` → `diffReadDictionary` → `diffReadContent`，通过 `graphDiffReadingContext` 维护 base/imported/referenced 三类图的节点偏移 (`graphOffsets`) 以及虚拟图索引到 delta 索引的双向映射 (`virtualToDeltaTranslations` / `deltaToVirtualTranslations`)；`deltaSpanT` 以 `deltas`+`cumulativeCount`+`span` 压缩表示连续相同段，配合 `readEntries`/`forEntries` 回调驱动 IRI/Blank Node 与三元组内容两阶段解析。
- `sststwritediff.go` 负责从两个 SST 流计算差分并写出。入口 `SstWriteDiff` 同样分 Header/Dictionay/Content 三段，先比较 imported/referenced NamedGraph 列表得到 `diffWriteGraph`（含 span），再对当前图的 IRI/Blank Node 执行 `computeDiffNodesDictionary` 生成 `diffWriteCombinedNode`，最后输出三元组变更；可选返回 `[]DiffTriple` 文本描述，并通过 `renderDiffWithCollections` / `reorderCollectionsAfterFirstObjectReference` 将 rdf:first 链聚合成 `<TermCollection>` 行并按 -1/0/+1 顺序排列。
- `sstutils.go` 提供共享基础设施：`allocateTriplexes`/`createAllocatedNode` 预分配三元组存储；`ibNode.sortAndCountTriples*` 按 triplex kind 排序并统计 TermCollection/非 TermCollection 成员数；`triplexComparator`、`compareIBNodes`、`compareLiterals`、`compareLiteralCollections` 定义稳定排序规则；`appendUnique*Triple` 系列在写入时自动建立双向索引三元组；`fillRdfFirstPlaceholder` 延迟填充 rdf:first 占位；`forMemberNodeRange`/`forPropLiteralRange` 等范围遍历器用于增量读取三元组。
依赖方向单向：`sststreaddiff.go` 与 `sststwritediff.go` 均依赖 `sstutils.go` 中的 IBNode 操作与排序工具，二者之间不互相引用，仅通过共享的 `diffEntry*` 常量与 `readUint/readString` 等底层编解码保持协议一致。
