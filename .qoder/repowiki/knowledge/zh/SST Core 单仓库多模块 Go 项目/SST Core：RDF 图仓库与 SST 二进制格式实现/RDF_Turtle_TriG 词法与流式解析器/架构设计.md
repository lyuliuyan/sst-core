模块按“词法层 → 语法层”分层组织：
- `rdflex.go` 提供底层 `lexer`，基于 Go 标准库模板的状态机（`stateFn`）在独立 goroutine 中通过 `tokens chan token` 异步产出 `tokenType`（IRI、Literal、PrefixLabel、GraphStart/End 等），支持单引号/三引号字面量、数字/布尔/XSD 类型、`@prefix`/`BASE`/`PREFIX`/`BASE` 指令以及 TriG 的 `{ }` 图块标记；并提供 `newLexer`（多行模式）和 `newLineLexer`（N-Triples/N-Quads 单行模式）两种构造方式。
- `rdfttl.go` 定义 `ttlReader`，封装 3 token 前瞻缓冲、`ctxStack` 上下文栈（`ctxTop/ctxList/ctxColl`）、命名空间映射 `ns` 与 `base` IRI，并通过 `parseStart → parseSubject → parsePredicate → parseObject → parseEnd` 的状态机函数链解析 Turtle 三元组，同时处理属性列表 `[...]` 与集合 `( ... )` 展开为 `rdf:first`/`rdf:rest`/`rdf:nil` 链。
- `rdftrig.go` 定义 `trigReader`，以组合方式嵌入 `*ttlReader`，在其外层维护 `currentGraph` 与 `graphStack`，在 `read()` 时捕获每次状态机运行期间新增的 triples 并关联到当前命名图，从而在不改变 TTL 解析逻辑的前提下扩展出 TriG 的 named graph 语义。
依赖方向单向：`rdftrig → rdfttl → rdflex`，上层仅消费 `token` 流，不反向调用词法器。错误统一通过 `errorf` panic + `recover` 转为 error 返回。
