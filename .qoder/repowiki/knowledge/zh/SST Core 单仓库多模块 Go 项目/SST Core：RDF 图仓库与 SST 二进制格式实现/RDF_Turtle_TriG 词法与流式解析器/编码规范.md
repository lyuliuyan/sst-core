- 解析器采用“状态函数”模式：每个解析阶段定义为 `func(*reader) parseFn`，返回下一个状态或 nil 表示结束，便于组合与复用。
- 词法分析通过 `stateFn func(*lexer) stateFn` 状态机驱动，由 `run()` 循环调度，新输入通过 `feed()` 追加并在 EOF 时关闭 tokens channel 通知结束。
- 错误处理统一通过 `errorf` 抛出结构化错误，再由 `defer recover` 捕获并写入 `*error` 指针，避免 panic 逃逸到调用方。
- TTL 解析使用 3 token 前瞻缓冲（`tokens[3]` + `peekCount`）配合 `next/peek/backup/backup2/backup3` 进行回溯，而非重新读取输入。
- 命名空间前缀通过 `ns map[string]string` 在解析 `@prefix`/`PREFIX` 时注册，遇到 `tokenPrefixLabel` 后拼接后缀并解析为绝对 IRI。
- 空白节点 ID 通过递增计数器 `blankNodeN` 生成形如 `_bN` 的唯一标识，用于匿名 BNode、属性列表与集合展开。
