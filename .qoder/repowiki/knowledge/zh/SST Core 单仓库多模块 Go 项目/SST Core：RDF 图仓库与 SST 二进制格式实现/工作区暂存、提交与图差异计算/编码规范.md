- 错误通过包级 `var` 集中声明（如 `ErrStageDeletedOrInvalid`、`ErrPreCommitConditionFailed`、`ErrCommitNotFound`），并在返回时配合 `wrapError` 包装。
- 长耗时或复杂操作（如 `MoveAndMerge`）使用 `MoveAndMergeReport` 记录每一步动作，通过 `report.AddAction` 追加带类型、目标图、描述和统计计数的 `MergeAction`，并以 JSON 形式输出。
- Stage 内部状态通过 `localGraphs` 与 `referencedGraphs` 双映射区分本地可写与只读引用，所有跨 Stage 移动都伴随 `updateNgTriples` 重绑 IBNode 三元组引用。
- 差异计算采用回调驱动：定义 `deltaGraphCallback`/`deltaNodeCallback` 接口，由 `deltaGraph` 统一调度删除/创建/修改路径，具体消费逻辑由调用方实现。
- 对有序集合的增量比较统一使用双指针归并模式（`i,j` 索引推进），在 `forPropSubjectRanger`/`forPropLiteralRanger`/`forPropLiteralCollectionRanger` 三种三元组类别上复用同一套 diff 模板。
