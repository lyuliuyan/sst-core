- 三元组对象的转换统一通过 `switch obj.rdfTermType()` 分支处理 IRI、Blank、Literal 三种情况，未知类型走 panic/default 分支。
- 字面量类型转换集中在 `convertLiteral` 中按 XSD URI 字符串匹配，再根据 `Typed()` 返回的具体 Go 类型做类型断言与数值解析。
- IRI 节点获取遵循 base+fragment 拆分模式：先查本地 `NamedGraph`，未命中则回退到引用图，空 fragment 对应 NamedGraph 自身节点。
- 空白节点通过 `context.blankNodes` 缓存 label→IBNode 映射，避免同一文件中重复声明产生多个节点实例。
- RDF collection 的识别与重建采用递归 `crawlCollectionUsers` 遍历 `rdf:first`/`rdf:rest` 链，收集后再一次性构造 `TermCollection` 并删除临时三元组。
- 错误信息通过 `fileLineError` 包装，将解析器的 token 编号错误还原为语义化名称并追加 `filename:line:` 前缀。
