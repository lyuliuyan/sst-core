本模块由三个文件组成，围绕 `Stage`/`NamedGraph` 抽象完成从三元组流到图结构的构建：
- `rdfreaderstage.go` 提供核心转换逻辑：`convertTripleSubjectInStage`、`convertTripleObjectInStage`、`iriToNodeInStage`、`blankToIBNodeInStage` 将解析出的 `rdfTypeSubject`/`rdfTypeObject` 映射为 `IBNode`/`Term`；`convertLiteral` 按 XSD 类型将字面量转换为 `String`/`LangString`/`Double`/`Integer`/`Boolean` 等；`extractCollections` + `crawlCollectionUsers` 递归扫描 `rdf:first`/`rdf:rest` 链并重建为 `TermCollection`；IRI 通过 base+fragment 拆分后在本地或引用的 `NamedGraph` 中查找/创建节点。
- `rdfreadlinenumber.go` 定义 `sliceReader` 接口和 `lineNumberReader`，包装底层 reader 以按 `\n` 切分并维护当前行号；`fileLineError` 将解析器产生的 token 编号错误还原为人类可读的错误消息（如 `unexpected EOF as EOL`），并附加文件名与行号。
- `rdfreadnamedgraph_test.go` 使用 `fromReaderToStage`、`newTripleReader` 等内部 API 对多种 Turtle 场景（命名图、导入、对象集合、嵌套属性列表、尾部分号、波浪号转义等）进行断言式验证。
依赖方向单向：测试 → 转换函数 → Stage/NamedGraph 抽象；行号错误包装仅作为错误增强层被上层调用。
