- 所有对外错误使用包级 `var ( ... )` 集中声明的 sentinel error，并通过 `&fs.PathError{Op, Path, Err}` 包装后返回，以符合 wrfs 的错误约定。
- 文件系统结构体通过编译期断言 `_ fs.FS = (*xxx)(nil)`、`_ fs.ReadDirFS`、`_ fs.OpenFileFS`、`_ fs.File`、`_ fs.FileInfo` 等方式显式实现 wrfs 接口。
- UUID 既作为文件名也作为 bbolt 键，打开文件时对路径调用 `uuid.Parse` 进行校验，非法路径直接返回 `PathError`。
- 目录项统一用 `dirEntry{nameKey, size}` 表示，实现 `fs.DirEntry` 与 `fs.FileInfo`，并以只读模式 `0o444` 暴露。
- 根目录 `.` 统一返回 `namedDirFile{name: "."}`，其 `Read` 返回 `errIsDir`，禁止对目录执行读取操作。
- 写入路径采用先缓冲再落盘的策略：`stageFileReadWriter` 使用 `bytes.Buffer` 累积数据，在 `Close()` 时计算 SHA256 并去重写入 `NamedGraphs`，再将 UUID→Hash 映射写入 `Stages`。
