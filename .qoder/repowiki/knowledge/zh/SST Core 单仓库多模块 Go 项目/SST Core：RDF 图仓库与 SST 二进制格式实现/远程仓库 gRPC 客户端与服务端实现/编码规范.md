- 所有面向 gRPC 的方法在进入业务逻辑前先调用 `r.enter()`，并在退出时 `defer r.leave()`，以统一执行仓库状态检查与并发计数。
- 每个 gRPC 调用前从 `context` 中提取 `sstauth.AuthProviderFromContext`，若存在则通过 `oauth.NewOauthAccess(token)` 附加 PerRPCCredentials。
- 分页查询（如 ListDatasets、FetchDatasets）统一采用 PageToken/NextPageToken 循环拉取直到 NextPageToken 为空。
- 服务端方法通过 `repositoryMethodRoles` 映射表声明所需最小 AccessMode，并由 RBAC 拦截器集中校验，而非在每个 handler 内重复判断权限。
- 错误统一通过 `wrapError` 或 `status.Errorf` 包装，并将 gRPC NotFound/Unknown 等状态码映射回领域错误（如 ErrDatasetNotFound、ErrRepoNotFound）。
- 服务端拦截器链按固定顺序组装：status converter → 可选 verbose log → recovery → auth → RBAC，再统一通过 `grpc.ChainUnaryInterceptor` / `ChainStreamInterceptor` 注册。
