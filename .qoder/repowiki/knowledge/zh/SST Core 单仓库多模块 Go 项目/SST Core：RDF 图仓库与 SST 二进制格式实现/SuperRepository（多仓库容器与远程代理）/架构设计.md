模块以 `SuperRepository` 接口为边界，定义 Get/Create/Delete/List/Quota/MaxRepositoryCount/RegisterIndexHandler/Close 等统一操作；本地实现 `localSuperRepository` 通过 `file://` URL 指向根目录，内部维护 `repos`（已打开的 Repository 缓存）、`known`（磁盘上存在的仓库名集合）和持久化的 `super-repo-quotas.json` 配额文件，使用 `sync.RWMutex` 保护并发访问，并通过 `bboltproto.RepoManagerServiceServer` 暴露 gRPC 服务；远程实现 `remoteSuperRepository` 通过 `grpc://` URL 连接远端，所有写操作经 `RepoManagerServiceClient` 转发，读操作则构造 `remoteRepository` 直接调用 Dataset/Commit/Index 服务；`NewSuperServer` 将本地 SuperRepository 包装为 gRPC 服务器，注册 Dataset、Ref、Commit、Index、RepoManager 五类服务并启用 reflection；`repocheckout.go` 中的 `checkoutCommitFromCommitDetails` 是跨仓库 checkout 的辅助函数，按 IRI 排序后逐个数据集 checkout 再 `MoveAndMerge` 合并结果。依赖方向：本地/远程实现均依赖 `bboltproto`、`bleveproto` 生成的 gRPC 客户端/服务端 stub，以及 `sstauth` 提供的 per-RPC OAuth 凭据注入。
