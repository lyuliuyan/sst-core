本模块由三个文件组成，分别承担两类支撑职责：
- `vocabulary.go`：定义 SST 的词汇体系——`Vocabulary`、`Element`、`ElementInfo` 及 `ElementInformer` 接口，通过全局 `vocabularyMap` 将编译期生成的本体元素映射到运行时信息；`dictionaryStage` 包装一个只读的 `Stage`，借助 `sync.Once` 惰性初始化并挂载到嵌入的 SST 词典仓库，对外暴露 `StaticDictionary()` 单例访问；`RegisterDictionary` 在包启动时注册词汇表、命名空间前缀映射和嵌入式文件系统。
- `vault.go`：实现基于内容哈希的不可变文档保险库，按 `hash[0]` 作为子目录、剩余字节拼接为文件名进行扁平化分片存储，提供 `StoreStreamToVault` 写入与 `vaultPath` 路径构造。
- `doc.go`：声明包级入口，说明 SST Core API 的主要类型边界（Repository、Dataset、Stage、NamedGraph、IBNode）。
依赖方向单向向外：本模块依赖 SST 核心接口（Stage、Repository、NamedGraph、IBNode、Hash 等），不反向被其他 sst 子包引用，属于顶层支撑层。
