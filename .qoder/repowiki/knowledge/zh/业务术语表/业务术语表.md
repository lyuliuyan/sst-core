### NamedGraph
- 定义：SST 中 RDF 三元组的基本组织单元，每个 NamedGraph 由一个 IRI 标识，包含一组 subject-predicate-object 三元组；SST 强制所有 IRI subject 的 fragment 属于该 NamedGraph，体现“所有权”语义。
- 别名：NG、命名图

### Dataset
- 定义：由一个默认 NamedGraph 以及通过 `owl:import` 直接或间接导入的所有 NamedGraph 共同组成的集合；Dataset 与其默认 NamedGraph 共享同一个 base IRI 标识。
- 别名：数据集

### Stage
- 定义：SST Repository 中某个 Dataset 及其全部导入 NamedGraph 的内存视图，可在其中修改数据后再提交为新的 revision。
- 别名：工作区、暂存区

### Commit
- 定义：记录对 Dataset/NamedGraph 的一次变更，包含时间戳、committer/author 身份、注释、受影响的 Dataset revision 以及父 commit 链；0 个父 commit 表示新建，1 个表示简单修改，多个表示合并。
- 别名：提交

### Revision
- 定义：包括 NamedGraphRevision（单个二进制 NamedGraph 文件的特定版本，以 SHA256 标识）和 DatasetRevision（整个 Dataset 的特定版本，由默认 NG 及其导入 NG 的若干 NamedGraphRevision 组成）。
- 别名：版本

### SST Repository
- 定义：类似 Git 的版本控制系统，但只管理二进制 NamedGraph 文件（.sst），通过 commit 链追踪 Dataset 与 NamedGraph 的历史变更，可本地或远程（通过 SST Protocol/gRPC）访问。
- 别名：仓库、SST 仓库

### SuperRepository
- 定义：管理多个独立 Repository 的顶层服务；每个被管理的 Repository 称为“Repository Entry”，SuperRepository 提供创建、删除、配额管理等操作。
- 别名：超级仓库、SuperRepo

### RepositoryEntry
- 定义：被 SuperRepository 管理的单个子仓库，拥有独立的 audience 标识 `<superClientID>#<repoName>` 和独立的 Keycloak client 配置。
- 别名：子仓库、仓库条目

### AccessMode
- 定义：SST 内部有序整数权限级别，从高到低依次为 none、read-only、read-write、admin、super-admin；高阶模式包含低阶模式的全部权限。
- 别名：访问模式、权限等级

### PerRepoAuth
- 定义：SST 服务器的两种授权模型开关：`false` 为单仓库模式，token 的 aud 必须等于服务器 ClientID；`true` 为 SuperRepository 模式，每个子仓库有独立的 `<superClientID>#<repoName>` 受众。
- 别名：按仓库鉴权、per-repo auth

### IBNode
- 定义：IRI node 与 blank node 的统称，即 RDF 三元组中的 subject/predicate 节点类型；SST 中 IBNode 由所属 NamedGraph 拥有。
- 别名：IRI/空白节点

### NG-SST 文件
- 定义：SST 的二进制格式文件，存储单个 NamedGraph 的特定 revision 及其全部三元组，自包含且引用其他 NamedGraph，文件名由其 SHA256 哈希决定。
- 别名：SST 文件、二进制 NamedGraph

### 早绑定 / 晚绑定
- 定义：SST Compiler 将 SST Ontology（ttl）编译为 Go 代码以实现编译期检查的“早绑定”；而通过字符串 URI 引用外部 ontology 的方式为“晚绑定”，仅在运行时校验。
- 别名：early binding、late binding
